# 42 Piscine

> The month-long entrance bootcamp of 42.

## What's inside

- Shell exercises
- C programming basics
- Problem-solving and peer learning
- Daily exercises and exams

## Usage

Exercises are organised by day, in folders named after the subjects (shell00, C00, ...).
